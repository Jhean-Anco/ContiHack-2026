# Arte y recursos visuales del PMV

## Flujo de creación

Cuando el prototipo necesite personajes, espacios o elementos visuales, el proveedor elegido para generarlos es ChatGPT; también pueden usarse aplicaciones externas de ilustración/diseño. La generación es parte del flujo de creación, no una función de IA en tiempo real para el jugador. Mantener arte modular y coherente para una experiencia web ligera. La elección de proveedor no equivale a tener activos generados o aprobados.

1. Crear brief visual y prompt en español: elemento, función en la escena, estilo, encuadre, paleta y requisitos de accesibilidad.
2. Generar una propuesta con ChatGPT o una aplicación externa; conservar el original y las variantes de trabajo.
3. Revisar que no copie personajes, marcas, estilos identificables ni obras ajenas; comprobar los términos de uso de la herramienta usada.
4. Si la imagen evoca Huancayo o el Valle del Mantaro, solicitar revisión de una persona conocedora del contexto; evitar estereotipos, vestimenta o símbolos añadidos como decoración.
5. Guardar el archivo aprobado, su texto alternativo, créditos/provenance y estado de revisión. Usar una licencia compatible con el repositorio y registrar restricciones.
6. Optimizar tamaño/formato para web y verificar legibilidad, contraste y recorte en móvil/escritorio.

## Reglas de representación

- Los NPC son personajes ficticios; no representar como retratos documentales a personas históricas reales sin fuente y autorización apropiadas.
- La ilustración de Plaza Constitución debe rotularse como interpretación ficticia si no reproduce un registro arquitectónico verificado.
- No generar imágenes que aparenten ser fotografías de archivo, mapas oficiales, manuscritos originales o evidencia histórica.
- Una imagen creada por IA no valida por sí sola el contenido histórico ni cultural que representa.
- Ofrecer texto alternativo útil; no codificar información esencial solo en el color o en detalles visuales.

## Registro de activos

Mantener un registro junto a los recursos publicados con estos campos: `assetId`, ruta, tipo, propósito, autor/herramienta, fecha, prompt o brief, licencia/términos consultados, fuentes de referencia, texto alternativo, revisión cultural/editorial, estado y versión. No guardar prompts con datos personales ni subir archivos que contengan información privada.

No se han generado ni aprobado imágenes para el juego. Los archivos actuales de interfaz son parte del scaffold técnico.
