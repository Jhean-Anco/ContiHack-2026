# Registros de decisión de arquitectura (ADR)

Crear un archivo `NNNN-titulo.md` con: estado (propuesta/aceptada/rechazada/sustituida), fecha, contexto, decisión, alternativas, consecuencias, seguridad/privacidad, migración y enlaces. No usar ADR para saltarse revisión curricular. Cambios de alcance, tecnologías, persistencia infantil, cuentas, analítica y deployment requieren decisión registrada antes de implementarse.
