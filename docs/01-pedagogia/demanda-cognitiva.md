# Demanda cognitiva

## Propósito y límites

Esta ficha permite describir y comparar lo que un reto pide hacer. Es una herramienta de diseño interna: sus categorías y juicios no son estándares, desempeños ni niveles oficiales del CNEB. Las variantes para 1.º–5.º de Secundaria deben revisarse por separado con docentes/especialistas y probarse con estudiantes antes de usarse.

## Ficha obligatoria por variante

| Campo | Qué registrar |
|---|---|
| Identidad | `missionId`, `challengeId`, grado, versión y estado editorial. |
| Propósito interno | Acción cognitiva concreta que se espera observar, en lenguaje no curricular oficial. |
| Tarea y pasos | Instrucción literal, decisiones requeridas, número de pasos y dependencias entre ellos. |
| Insumos | Fuente/dato mostrado, contexto previo necesario, procedencia y forma de representación. |
| Operaciones | Por ejemplo localizar, comparar, clasificar, ordenar, inferir o justificar; definir solo las que realmente exige el ítem. |
| Representaciones | Texto, mapa, tabla, imagen u otra forma; cambios de representación y apoyos disponibles. |
| Lectura y vocabulario | Extensión, legibilidad, términos locales/técnicos, explicación disponible y comprensión no relacionada con el objetivo. |
| Respuesta | Formato, respuestas aceptadas, equivalencias, errores previsibles y criterio observable. |
| Ayudas | Pista graduada, repetición de instrucción, ejemplo neutral, lectores/teclado y posibilidad de reintento. |
| Revisión | Docente/especialista, fecha, evidencia de prueba, limitaciones y estado. |

## Criterios de contraste entre grados

No aumentar dificultad solo alargando textos, ocultando información, reduciendo tiempo o quitando ayudas. Identificar qué cambia en el razonamiento y por qué es apropiado; revisar accesibilidad, familiaridad del contexto y conocimiento que el reto enseña por sí mismo. Evitar que el acierto dependa de conocimiento histórico no proporcionado, velocidad lectora, precisión motora, percepción del color o uso previo de mapas digitales.

Para la misión propuesta, analizar por separado el trabajo con fuentes y la tarea espacial. Registrar si la matemática se limita a orientarse/comparar recorridos o si incorpora una representación o cálculo adicional; no asumir que escala, coordenadas o medición son apropiadas para cada grado sin revisión curricular y de demanda.
