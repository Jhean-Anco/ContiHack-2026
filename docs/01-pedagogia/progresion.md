# Progresión pedagógica y XP

## Dos sistemas independientes

**Progresión pedagógica:** concepto aún por diseñar. Si el producto llega a resumir evidencia, debe hacerlo por objetivo y contexto, con ayudas y oportunidades de reintento visibles. No equivale a nota, nivel curricular, diagnóstico ni atributo fijo de una persona.

**XP:** puntuación opcional de juego por acciones narrativas/recreativas descritas con transparencia. Puede desbloquear elementos cosméticos o narrativos; no sube ni baja la lectura pedagógica. El prototipo propuesto no requiere guardado de XP y puede omitirlo.

## Reglas

- XP no se calcula desde acierto, cantidad de intentos, velocidad ni uso de pistas como proxy de dominio.
- No usar XP para clasificar estudiantes, recomendarles contenido, inferir aprendizaje o informar a docentes/familias.
- No cerrar prácticas educativas esenciales por falta de XP.
- Mostrar reglas antes de la acción, permitir pausa/salida/reintento y evitar rachas punitivas o presión temporal.
- Si se usa evidencia pedagógica, explicar qué respuesta concreta la originó, incertidumbre y límites; el docente interpreta.
- No persistir progreso identificable por defecto. Toda persistencia requiere decisión de producto, privacidad y arquitectura.

## Estado actual

No existen progresión, XP ni desbloqueos implementados. El esquema de dominio futuro debe separar explícitamente recompensa lúdica de evidencia de reto.
