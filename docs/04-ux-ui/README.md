# UX/UI

Existe una primera interfaz del flujo de misión en `/jugar`, construida con contenido de ejemplo rotulado; la página técnica de salud de servicios se conserva en `/salud`. La UX del PMV sigue pendiente de prueba con la audiencia adolescente y de auditoría de accesibilidad: tener pantallas no acredita jugabilidad ni eficacia. Principios: una tarea principal por vista, instrucciones concretas sin tono infantilizante, controles reconocibles, ayudas disponibles, texto legible, privacidad explicada con claridad y controles reversibles.
